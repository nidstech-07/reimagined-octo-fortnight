Student Management System - Key Features

Student Lifecycle Management: Full CRUD operations to enroll, view, update, and remove student profiles.

Database Persistence: Relational database integration using MySQL for reliable and structured data storage.

Course & Grade Tracking: Assign courses to students, manage enrollments, and track academic grades.

Secure Data Access: Utilizes parameterized SQL queries to prevent SQL injection and secure database operations.

Search & Filtering: Quickly search student records by ID, name, course, or academic standing.
